=== CUSTOM FONT ===

Paste your .ttf or .otf font file into this folder. The whole game (menus, buttons, labels,
stats) will use it the next time you start the game. No rebuild needed.

- Best place on the handheld:  /data/roms/ports/SolitairProject/assets/fonts/
- If there are several fonts, "ui.ttf" / "ui.otf" is used; otherwise the first one (A-Z).
- Symbols your font does not have (like the card suits) fall back to the built-in font.
- No font here = the built-in font is used.
